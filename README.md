# Level-3 Term-1 Coursework Repository

## Overview

This repository contains coursework completed for Level-3, Term-1 at Bangladesh University of Engineering and Technology (BUET). It collects offline assignments, online assessments, and term project work from core computer science sessional courses taken during the first term of Level-3, presented clearly for learning, review, and archival.

## Repository Structure

The workspace includes course folders and supporting files. Key folders present in this workspace are:

- `CSE 310 - Compiler Sessional`
- `CSE 314 - OS Sessional`
- `CSE 316 - Microcontroller and Microprocessor sessional`
- `CSE 318 - AI Sessional`

Each directory contains offline assignments, online lab exam solutions, project code, and supporting materials.

## Term-1 Coursework Details

### 1. CSE 310: Compiler Sessional

#### Offlines
- **Offline 1:** Symbol Table implementation with scoped symbol management
- **Offline 2:** Lexical analysis and token recognition using ANTLR
- **Offline 3:** Syntax and semantic analysis using ANTLR
- **Offline 4:** Intermediate code generation and assembly output

#### Onlines
- **Online 1:** Scoped symbol insertion and lookup under constraints
- **Online 2:** Custom ANTLR lexer rules and token patterns
- **Online 3:** Grammar rule extension and in-lab semantic checks
- **Online 4:** Target assembly generation for control flow and expressions

---

### 2. CSE 314: Operating Systems Sessional

#### Offlines
- **Offline 1:** Shell scripting with Bash for automated file processing
- **Offline 2:** Thread synchronization using mutex locks and semaphores
- **Offline 3:** Adding custom system calls to the xv6 kernel
- **Offline 4:** CPU scheduling in xv6

#### Onlines
- **Online 1:** Bash scripting lab test
- **Online 2:** Concurrency and race condition resolution
- **Online 3:** In-lab kernel modification and system call handling
- **Online 4:** Custom scheduling in xv6

---

### 3. CSE 316: Microcontroller and Microprocessor Sessional

#### Onlines
- **Online 1:** 8086 Assembly on Recursion
- **Online 2:** Microcontroller circuit simulation and display logic
- **Online 3:** Interrupt-driven event and timer implementation

#### Project
- **Tetris on LED Matrix:** A Tetris game built with an ATmega32 microcontroller and an LED matrix.

---

### 4. CSE 318: Artificial Intelligence Sessional

#### Offlines
- **Offline 1:** N-Puzzle problem using $A^*$ search with heuristics
- **Offline 2:** Adversarial search on Mancala using Minimax with $\alpha$-$\beta$ pruning
- **Offline 3:** Max-Cut problem using Local Search and GRASP
- **Offline 4:** Constraint Satisfaction Problem (CSP) using Backtracking with heuristics

#### Onlines
- **Online 1:** Custom heuristic evaluation function for search
- **Online 2:** Game tree search modification and board evaluation
- **Online 3:** Local search neighborhood selection
- **Online 4:** Custom constraint modeling and propagation
